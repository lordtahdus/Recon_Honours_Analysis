t-Reconciliation

Introduction

This vignette shows how to perform t-student reconciliation. The key idea is to place a prior distribution on the covariance matrix of the residuals, thereby accounting for its uncertainty.

By choosing the Inverse-Wishart distribution as the prior, the reconciliation can be computed in closed form. As a result, the reconciled predictive distribution becomes a multivariate t-distribution.

The example presented uses monthly Swiss overnight stays data, which are publicly available on the official website of the Swiss Confederation. The data are treated as continuous, and the hierarchical structure is cross-sectional, consisting of two levels: the national total and the division by canton.

The dataset spans the period from January 2005 to January 2025, comprising 241 monthly observations.

Reconciliation

The base forecasts are generated using the ets() function from the forecast package, which fits exponential smoothing models to each time series.

To address potential instability in the estimation of the residual covariance matrix, particularly when the number of observations is limited, we apply a slight shrinkage to the sample covariance matrix.


##############################Base forecasts#####################################
base_fc = matrix(NA, ncol = h, nrow = n)
res = matrix(NA, ncol = n, nrow = L)
for (i in 1:n){
    models = forecast::ets(ts(train[,i ], frequency = freq), model = "AZZ")
    f = forecast(models, h = h)
    base_fc[i, ] = f$mean
    res[, i] = models$residuals
}

Sigma = crossprod(res)/nrow(res)
Sigmahat = (1 - 10^-4)* Sigma + 10^-4 * diag(diag(Sigma))

The Inverse-Wishart distribution used as a prior has two parameters: the degrees of freedom \(\nu\), and the scale matrix \(\Sigma\).

The prior parameters are computed as follows:

  • \(\Sigma_0\) is set as the covariance matrix of the residuals obtained from either the naive or seasonal naive forecasting methods, fitted on the training set.
    If the training set is too short, specifically, shorter than twice the seasonal frequency, only the naive model is used to compute \(\Sigma_0\).
    This is because the seasonal naive method requires at least two seasonal cycles to produce meaningful residuals, and fewer than two observations per season are insufficient to estimate the prior.

  • \(\nu_0\) is estimated by maximizing the sum of the log of the leave-one-out t-Student predictive distributions.
    This objective function is referred to as objective_function in the code below.

#####################Prior parameters computation###############################
res_naive = matrix(NA, ncol = n, nrow = L)
if (nrow(train) <= 2*freq){
      for (i in 1:n){
          models = forecast::naive(ts(train[,i ]))
          f = forecast(models, h = h)
          res_naive[, i] = models$residuals
      }
  
    res = res[2:nrow(train), ]
   }else{
        for (i in 1:n){
            models = if (check.seasonality[i]) {
              forecast::snaive(ts(train[,i], frequency = freq))
            }else {
                forecast::naive(ts(train[i,]))}
            f = forecast(models, h = h)
            res_naive[, i] = models$residuals
        }
      res_naive = res_naive[(freq + 1):nrow(train), ]
   }
    
      
      naive_mat = schaferStrimmer_cov(res_naive)$shrink_cov
      
      
    n_obs = nrow(res_naive)
    n_obs_effective = round(0.1*n_obs)
    inv_sigma_fun = function(x){solve(((naive_mat * (x - n - 1)) + crossprod(res_naive)))}
    log_det_sigma_fun = function(x){sum(log(eigen(((naive_mat * (x - n - 1)) + 
                                                 crossprod(res_naive)))$values))}
    
    log_den_tz_inv_sigma_z_fun = function(l, inv_sigma){log((1 - (((res_naive[l, ])%*%inv_sigma%*%(res_naive[l,])))))}
    
    objective_function = function(x){
      inv_sigma = inv_sigma_fun(x)
      
      log_det_sigma = log_det_sigma_fun(x)
      
      - ((n_obs - n_obs_effective)*(lgamma((x + n_obs)/2)- 
                                      lgamma((x + n_obs - n)/2) -
           (log_det_sigma/2)) + ((x + n_obs - 1)/2)*
           sum(sort(vapply(1:n_obs, function(l){log_den_tz_inv_sigma_z_fun(l, inv_sigma)}, 
                   numeric(1)))[(n_obs_effective + 1):n_obs]))
    }
    
    initial_guess = n + 2
    
    lower_bounds = n + 2
    upper_bounds = 5*n
    
    opts = list("algorithm" = "NLOPT_LN_BOBYQA", "xtol_rel" = 10^-5, 
                "maxeval" = 1000)
    
    results = nloptr(x0 = initial_guess, eval_f = objective_function, 
                     lb = lower_bounds, ub = upper_bounds, opts = opts)
    
    prior.nu = results[[1]]
    prior.psi = (naive_mat)*(prior.nu - n - 1)

Since the Inverse-Wishart distribution is conjugate to the Multivariate Gaussian distribution, the posterior distribution of the covariance matrix remains an Inverse-Wishart with updated parameters.

These posterior parameters are then used during the reconciliation phase. The approach is conceptually similar to Gaussian reconciliation via conditioning (Zambon et al. 2024), with two key differences:

  • the reconciled distribution is a multivariate t-distribution;
  • the incoherence term (\(|\mathbf{A} \mathbf{\hat{b}} - \hat{u}|\)) appears in the scale parameter, allowing for a more flexible representation of uncertainty.
####################t-Reconciliation##########################################

posterior.psi = (n_obs * Sigmahat) + prior.psi
posterior.nu = prior.nu + n_obs
Psi_u = posterior.psi[1:n_u, 1:n_u]
Psi_b = posterior.psi[(n_u + 1):n, (n_u + 1):n]
Psi_ub = posterior.psi[1:n_u, (n_u + 1):n, drop = FALSE]
mu_u = base_fc[1:n_u]
mu_b = base_fc[(n_u + 1):n]
inco = ((A %*% mu_b) - mu_u)
Q = Psi_u - (Psi_ub %*% t(A)) - (A %*% t(Psi_ub)) + (A %*% 
                                                       Psi_b %*% t(A))
invQ = solve(Q)
C = 1 + ((t(inco) %*% invQ %*% inco))
nu_b_tilde = posterior.nu - n_b + 1
mu_b_tilde = mu_b + (t(Psi_ub) - Psi_b %*% t(A)) %*% 
  invQ %*% inco
Sigma_b_tilde = as.numeric(C/nu_b_tilde) * (Psi_b - ((t(Psi_ub) - (Psi_b %*% t(A))) %*% 
                                                         invQ %*% t(t(Psi_ub) - (Psi_b %*% t(A)))))
  
  

#######################t-Student predictive distribution###################### 
t_Rec_reconciled_mean = S %*% mu_b_tilde
t_Rec_scale_par = S %*% Sigma_b_tilde %*% t(S)
t_Rec_df = nu_b_tilde
